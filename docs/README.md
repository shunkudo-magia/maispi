## アプリ概要（前提）

- **まいすぴ** = 月齢・運気・診断を扱うスピリチュアル系メディアアプリ
- 技術: Expo + React Native + TypeScript / ヘッドレスCMS = **microCMS**
- コンテンツ構造: **特集（Feature）→ 記事（Article）** の2階層
- カテゴリ: `LOVE / MONEY / FAMILY / BODY / WORK / SPIRIT` の6種

> 注: 各文書中の `（要確認 / MTGで確定）` はまだ決まっていない項目です。
