# 記事執筆ルール（草案）

> 本書はアプリの記事レンダリング実装（`src/components/ui/ArticleBody.tsx`）と既存サンプル（`src/lib/cms/mock.ts`）を根拠にした **草案** です。文字数などの `（要確認 / MTGで確定）` 項目は定例MTGで確定します。

## 1. 使用可能な HTML タグ（重要）

記事本文（microCMS richtext）はアプリ側で `react-native-render-html` によって描画されます。**スタイルが定義されているタグは以下のみ** です（`ArticleBody.tsx` の `tagsStyles`）。

| タグ | 用途 | 表示スタイル |
|------|------|--------------|
| `<p>` | 本文段落 | ゴシック体（Noto Sans JP）／行間1.9／段落下マージン |
| `<h2>` | 章見出し | 明朝体・太字（Shippori Mincho Bold）／大きめ |
| `<h3>` | 小見出し | 明朝体・中字（Shippori Mincho Medium） |
| `<a>` | リンク | primary色（#da668e）・**下線なし** |
| `<strong>` | 強調 | ゴシック太字 |

> ⚠️ **上記以外のタグ（`<ul>` / `<li>` / `<blockquote>` / `<img>` / `<table>` / `<hr>` など）は専用スタイルが無く、表示が崩れる・意図しない見た目になる恐れがあります。** 使用する場合は事前に開発へ表示確認を依頼してください（[開発との確認事項](./dev-coordination.md)）。

## 2. 見出しの使い分け

- `<h2>` … 記事内の大きな区切り（章）。明朝体で世界観を演出。
- `<h3>` … `<h2>` 配下の小見出し。
- 見出しの**飛び級（h2を飛ばしてh3）は避ける**。
- タイトル（記事の `title`）は本文中に `<h1>` として書かない（タイトルは別フィールド）。

## 3. トーン＆マナー

既存サンプル記事の文体を基準とします（例: 「満月の夜に告白すべき理由」「引き寄せを加速する言葉の使い方」）。

- **モチーフ**: 月齢・月相・占星術・引き寄せなどスピリチュアルな世界観
- **語り口**: 読者に寄り添う、やさしく前向きな語りかけ調
- **NG**: 断定的な医療・投資の効果保証、不安を過度に煽る表現
- 占い・スピリチュアル領域のため、**効能の断定や誤認を招く表現に注意**（薬機法・景表法の観点。最終判断は編集責任者）

## 4. 文章ボリューム目安（草案）

| 項目 | 草案値 | 備考 |
|------|--------|------|
| 記事タイトル | 15〜25文字程度 | （要確認 / MTGで確定） |
| 本文文字数 | 600〜1,200文字程度 | スマホ閲覧前提。mock記事は短め |
| 段落（`<p>`）の長さ | 2〜4文程度で改段 | 行間1.9のため詰まりすぎ注意 |
| `<h2>` の数 | 長文記事で1〜3個 | 短い記事は見出しなしでも可 |

## 5. microCMS richtext 運用上の注意

- リンクは **下線が表示されません**。リンクである旨が本文から伝わる文言にする。
- richtext エディタが上記以外のタグを自動生成する場合があるため、入稿後はアプリ実機（またはプレビュー）で表示崩れがないか確認することを推奨。
- 画像の本文埋め込み（`<img>`）はアプリ側未対応の可能性が高い → 使う場合は[開発と要調整](./dev-coordination.md)。

## 6. 入稿前チェックリスト

- [ ] 使用タグが `p / h2 / h3 / a / strong` の範囲内か
- [ ] `category` が所属特集と一致しているか
- [ ] 特集（`featureId` / 参照フィールド）が正しく紐づいているか
- [ ] 効能断定・不適切表現がないか
- [ ] `publishedAt` を設定したか
