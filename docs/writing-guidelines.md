# 記事執筆ルール（草案）

> **Webメディア（直近）** と **RN/Expoアプリ（将来）** 両対応の **草案** です。`（要確認 / MTGで確定）` はMTGで確定します。
> 根拠: Drive `maisupi-article-plan-30-v3.xlsx`、アプリ実装 `src/components/ui/ArticleBody.tsx`。

## 1. 共通の執筆方針

- **文字数**: 1記事 **2,000字以内**（記事プラン準拠）。
- **構成**: H2見出しベースの章立て（マスターの「構成案（H2見出し）」に沿う）。典型は4章構成（例: ①誤解/落とし穴 → ②データ・調査 → ③具体的方法 → ④今日できる一歩）。
- **読後感**: 「**罪悪感なき他責帰結**」— 読者を責めず、原因を外部要因に置きつつ前向きな一歩に着地させる。
- **トーン&マナー**: スピリチュアル×実用。月齢・占星術・儀式などのモチーフを、データ/取材で裏づけて語る。読者に寄り添う語りかけ調。
- **著者**: 記事は著者名義で執筆（[企画ルール](./content-planning-rules.md)）。著者ごとの専門領域・口調を保つ。
- **画像**: アイキャッチ16:9 + 本文挿絵4:3×2。カテゴリ別パレット（[デザイン](./design-branding.md)）。`no text / no human faces`。

## 2. コンプライアンス（重要）

占い・スピリチュアル領域のため、表現に注意:
- 医療・健康・投資などで **効果を断定しない**（薬機法・景表法）。
- 不安を過度に煽らない。
- 最終的な表現可否は **法務確認**（[インフラ洗い出し](./infra-launch-checklist.md)）。

## 3. Webメディア（HTML / Vercel）

- 静的HTMLとして公開（`d-lips-style`ベース）。
- 見出し階層・OGP（SNSシェア用のタイトル/説明/画像）を記事ごとに設定（[機能仕様](./feature-spec.md) SNSシェア）。

## 4. アプリ（microCMS richtext）— 将来トラック

アプリ表示は `react-native-render-html` で描画。**スタイル定義のあるタグのみ**使用可（`ArticleBody.tsx`）:

| タグ | 用途 | スタイル |
|------|------|----------|
| `<p>` | 本文 | ゴシック（Noto Sans JP）/ 行間1.9 |
| `<h2>` | 章見出し | 明朝太字（Shippori Mincho Bold） |
| `<h3>` | 小見出し | 明朝中字 |
| `<a>` | リンク | primary色・**下線なし** |
| `<strong>` | 強調 | ゴシック太字 |

> ⚠️ アプリでは上記以外のタグ（`ul/li/blockquote/img/table` 等）は未スタイルで表示が崩れる。Webメディアの記事をアプリへ流用する際は要変換・要確認（[開発との確認事項](./dev-coordination.md)）。
