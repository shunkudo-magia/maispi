# 記事企画ルール（草案）

> 本書はコードベースの現状（`src/lib/cms/types.ts` / `src/lib/cms/mock.ts` / `src/constants/colors.ts`）を根拠にした **草案** です。数値目標などの `（要確認 / MTGで確定）` 項目は定例MTGで確定します。

## 1. 企画の単位

企画は **「カテゴリ × 号（月号）」** を基本単位とします。

```
号（例: 2025年7月号）
└─ 特集（Feature） … カテゴリごとに1本
   └─ 記事（Article） … 特集配下に複数本
```

- **号** = 毎月のコンテンツ更新サイクル。特集の `subtitle` に `YYYY年M月号` として記録します（例: `2025年7月号`）。
- **特集（Feature）** = 各カテゴリ・各号のメインテーマ。1カテゴリにつき原則1本。
- **記事（Article）** = 特集を構成する個別コンテンツ。`featureId` で特集に紐づきます。

## 2. カテゴリ定義

カテゴリは以下6種に固定です（`src/constants/colors.ts` の `CategoryColors` 準拠）。新規カテゴリの追加はコード変更を伴うため開発と要相談。

| キー | ラベル | テーマの狙い | 配色(bg) |
|------|--------|--------------|----------|
| `love` | LOVE | 恋愛・パートナーシップ・引き寄せ | `#da668e` |
| `money` | MONEY | 金運・豊かさ・資産・リセット | `#d4940a` |
| `family` | FAMILY | 家族・人間関係・絆 | `#4eb89e` |
| `body` | BODY | 身体・健康・デトックス・セルフケア | `#7b68ee` |
| `work` | WORK | 仕事・キャリア・人間関係 | `#5b8dd9` |
| `spirit` | SPIRIT | 精神・スピリチュアル・内省 | `#e8803d` |

> ⚠️ **企画上の空白**: `WORK` と `SPIRIT` はコード上は色定義されていますが、現状サンプル（mock）に特集・記事がありません。初号でこの2カテゴリのコンテンツを用意するかを **MTGで確認**。

## 3. 1号あたりのボリューム目安（草案）

| 項目 | 草案値 | 備考 |
|------|--------|------|
| 1号あたりの特集本数 | 6本（全カテゴリ） / または注力カテゴリのみ | （要確認 / MTGで確定） |
| 1特集あたりの記事本数 | 3〜5本 | 現状mockは1〜2本。読み応えの観点から増やす想定 |
| 1記事の文字数 | 執筆ルール参照 | [記事執筆ルール](./writing-guidelines.md) |

## 4. 特集メタデータの記入規則

microCMS の `features` に登録する際の必須項目（`Feature` 型準拠）:

| フィールド | 必須 | 記入規則 |
|------------|------|----------|
| `title` | ✓ | 特集タイトル。世界観を表す訴求コピー（例: 「愛を引き寄せる月の引力」） |
| `category` | ✓ | 上記6キーのいずれか（小文字） |
| `subtitle` | ✓ | `YYYY年M月号` 形式（例: `2025年7月号`） |
| `coverImage` | 任意 | 特集カバー画像。アプリ側の表示対応は（要確認 / 開発調整） |

## 5. 記事メタデータの記入規則

microCMS の `articles` に登録する際（`Article` 型準拠）:

| フィールド | 必須 | 記入規則 |
|------------|------|----------|
| `title` | ✓ | 記事タイトル |
| `category` | ✓ | 所属特集と同じカテゴリ |
| `featureId`（CMSの参照フィールド名は要確認） | ✓ | 紐づく特集を選択 |
| `body` | ✓ | richtext本文。タグ制約は[執筆ルール](./writing-guidelines.md)参照 |
| `thumbnail` | 任意 | 記事サムネイル |

## 6. 企画フロー（草案）

1. **テーマ立案** — 当月の月相・季節・トレンドからテーマ案を出す
2. **カテゴリ割当** — 6カテゴリのどれに位置づけるか決める
3. **号への配置** — 当月号の特集として登録、記事構成（本数・見出し）を設計
4. **執筆 → 入稿** — [執筆ルール](./writing-guidelines.md)に沿って microCMS に登録
5. **公開設定** — `publishedAt` を設定（一覧は `-publishedAt` 降順で表示される）
